Every settings screen, in the order the app lists them.

On iPhone and iPad the root is a list: Alerts, Alert History, Server, Appearance & Display, Storage, About. On Mac the same material is split into tabs: General, Connection, Appearance, Alerts, Storage, Scrub Feel, About. Connection is Server; Alerts folds in Alert History.

Alerts

See Alerts and notifications for what these do in practice.

Row What it does
Set up alerts Runs the five step guided wizard: permission, posture, subjects, feel, review.
Alert notifications The master switch for push.
Notifications are off in iOS Settings Appears only when the system has denied notifications; links straight there.
Status What the app currently thinks the push chain's state is.
Current posture A readout of what the routing table resolves to right now, plus pause and quiet-hours state.
Recent decisions The last three routing decisions, linking to the full Alert History.
Attention Ladder The subject-by-place grid of Off, Log, Glance, Notify, Alarm, plus recognition relaxation.
Cameras One switch per camera: which cameras may notify this device.
Zones Per-zone area type, plus per-subject overrides for that zone.
Quiet Hours On or off, From and Until, and whether quiet hours are fully silent or only soundless.
Delivery & Display iPhone and iPad only: openings tracking, Live Activity first or Notifications first, a tuning mode, and a demo Live Activity.
Sounds & Alert Levels Mute all sounds, pick the escalation sound, and preview each alert level.
Push Doctor The six-check notification diagnostic.
Pause notifications 15 minutes, 1 hour, or until morning. Becomes Resume while paused.
Sync status Whether your settings have reached the server.

Alert History

A feed of routing decisions with a filter, grouped into stories showing how many times each mutated and how many devices it reached. Dimmed rows are decisions not to send. Swipe a row to mark it too much or not enough, or to silence it.

Server

Row What it does
Server URL, username, password The same credentials form as onboarding.
Save settings Commits the form, switching servers if you changed the address.
Test connection Checks before you commit.
Status The result of the last test.
Connection Doctor The seven-rung connection diagnostic.
Disconnect server Clears the saved server and credentials and returns you to setup. Confirms first.
Reset app Forgets the server, all settings, and zone classifications, and returns to the welcome screen. Confirms first.

See Connect to your server.

Appearance & Display

Row What it does
Camera order Drag the Live grid into a custom order, or reset to automatic grouping.
Live video tiles How many grid tiles stream live video at once. Auto is four on iPhone, six on iPad.
Hide event controls after When a camera's newest event is older than this, hide its Previous/Next chips and event card. One day through 30 days, or Never.
Time format How the scrubber writes times.

Debug builds also carry a Developer Labs section with theme, haptics, and reel-drive tuning. It is not in a release build.

Storage

Clear image cache empties the decoded image cache and the on-disk HTTP cache. The caption shows the current item count and size, so you can see whether it is worth doing.

About

The app version and build, plus links to this website, this documentation, and the privacy policy.

Mac-only tabs

Tab What it holds
General Launch at login.
Scrub Feel The four reel tuning sliders (Precision, Travel, Swipe threshold, Event drag), which live in the controls shade on iOS. They apply to every camera.
