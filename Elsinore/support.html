Quick answers

Cannot connect, or login fails. Check the server URL, including the port, and confirm you can reach that same address from a browser on the same device. Then run Settings › Server › Connection Doctor, which walks the whole chain and names the rung that broke.

Live view works but feels delayed. The app fell back to HLS because low-latency WebRTC media could not reach your device. This is common on restrictive networks and on plain reverse proxies. It is expected graceful degradation, not a bug. See Live.

Notifications are not arriving. Push requires the optional Marcellus sidecar running alongside Frigate, and notification permission granted to the app. Settings › Alerts › Connection Doctor runs the whole chain end to end. See Alerts.

The app cannot reach my server after a network change. Confirm your device's own network path (Wi-Fi, cellular, VPN or tailnet) can currently reach the address you configured.

Reporting a bug

Email helicopterrun@gmail.com. Please include:

  • The Elsinore version, from Settings › About.
  • Your Frigate version.
  • Your Marcellus sidecar version, if you run one.
  • The Connection Doctor output. Settings › Server › Connection Doctor produces a plain-text transcript with one PASS, WARN, FAIL, INFO, or SKIP line per rung; paste that in.
  • For a notification problem, the Connection Doctor output as well (Settings › Server › Connection Doctor).
  • What you expected, and what happened instead.
